# Phase 08 — Security Checklist

## مراجعة أمان الإطلاق

### 1. كلمات المرور والأسرار

- [ ] `BETTER_AUTH_SECRET` مُولَّد بأمان (`openssl rand -base64 32`)
- [ ] كلمة مرور PostgreSQL قوية ومختلفة عن الافتراضية
- [ ] جميع الأسرار في `.env.production` وليس في Git
- [ ] `.env.production` بصلاحيات محدودة (`chmod 600`)
- [ ] لا تسجيل لأي قيمة سرّية في السجلات

### 2. HTTPS والنقل

- [ ] شهادة SSL مُفعّلة (Let's Encrypt عبر Certbot)
- [ ] HSTS مُفعّل في الإنتاج
- [ ] جميع Cookies: `secure`, `httpOnly`, `sameSite=lax`

### 3. قاعدة البيانات

- [ ] PostgreSQL لا يقبل اتصالات خارجية (127.0.0.1 فقط)
- [ ] نسخ احتياطي يومي مُفعّل
- [ ] اختبار استعادة تم بنجاح
- [ ] `prisma migrate deploy` يُنفَّذ تلقائياً عند النشر

### 4. التطبيق

- [ ] `NODE_ENV=production` مُفعّل
- [ ] لا بيانات تجريبية في الإنتاج
- [ ] Health check يفحص DB وRedis
- [ ] Workers منفصلة عن Web process

### 5. المراقبة

- [ ] مراقبة صحة التطبيق (`monitor.sh`)
- [ ] تنبيهات عند فشل الخدمات
- [ ] تنبيهات عند ارتفاع استخدام القرص
- [ ] سجلات الأخطاء مُجمّعة

### 6. الخصوصية

- [ ] صفحة `/privacy` نشطة بمحتوى عربي
- [ ] صفحة `/terms` نشطة بمحتوى عربي
- [ ] سياسة حذف البيانات مُوثّقة
- [ ] بيانات الوكالة لا تُشارك مع أطراف ثالثة

### 7. النسخ الاحتياطي

- [ ] نسخ احتياطي يومي لقاعدة البيانات
- [ ] نسخ احتياطي أسبوعي للمجلد المشروع
- [ ] الاحتفاظ بالنسخ لمدة 14 يوماً على الأقل
- [ ] اختبار استعادة تم مرة واحدة على الأقل

### 8. CI/CD

- [ ] GitHub Actions pipeline يعمل على كل PR
- [ ] Lint + Typecheck + Tests تمر قبل الدمج
- [ ] نشر تلقائي إلى Staging عند الدمج في main
- [ ] نشر Production يتطلب موافقة يدوية
