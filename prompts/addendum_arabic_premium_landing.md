# Addendum — العربية كلغة أساسية + Landing Page بمستوى عالمي

هذا برومبت إضافي (Addendum) يُغذّى لـ opencode بنفس جلسة المشروع (`--continue`)، فوق ما تم تنفيذه أصلًا. الهدف: (1) جعل اللغة العربية RTL هي اللغة الافتراضية والأساسية لكل المنصة، و(2) رفع مستوى تصميم الـ Landing Page ليصير بجودة بصرية عالمية (مستوى Stripe / Linear / Vercel / Framer)، بدل تصميم عام أو تعليمي الشكل.

هذا لا يلغي أي شيء من `docs/16_UI_UX.md` أو `docs/06_TECH_STACK.md` — هو تشديد وتفصيل إضافي فوقهم. طبّق التعليمات التالية على كل ما تم بناؤه حتى الآن (Landing، صفحات Auth، أي صفحة موجودة)، وعلى كل ما سيُبنى لاحقًا في المراحل القادمة.

---

## 1) العربية هي اللغة الافتراضية (ليست مجرد لغة مدعومة)

- المسار الجذري `/` يعرض المحتوى بالعربية واتجاه `rtl` مباشرة، بدون أي Redirect أو صفحة اختيار لغة أولى.
- الإنجليزية متاحة كلغة ثانوية عبر مبدّل لغة واضح في الـ Header (مثلاً `/en`)، وليس العكس.
- استخدم `next-intl` (أو المكافئ المذكور في `docs/06_TECH_STACK.md`) مع ملفات ترجمة منفصلة: `messages/ar.json` و`messages/en.json`. لا نصوص عربية أو إنجليزية مكتوبة مباشرة (Hardcoded) داخل الكومبوننتس — كل نص عبر مفتاح ترجمة.
- `<html lang="ar" dir="rtl">` هو الافتراضي عند تحميل أي صفحة عربية. تأكد أن كل مكوّنات shadcn/ui (القوائم المنسدلة، الـ Drawer، الأسهم، اتجاه الأيقونات كـ "التالي/السابق") تنعكس صح بصريًا بالعربي، وليس فقط النص.
- اختر خط عربي احترافي ومقروء (مثل **IBM Plex Sans Arabic** أو **Tajawal** أو **Cairo**) مع خط إنجليزي متجانس معه (مثل **Inter**) كـ fallback، وأضفهما في Tailwind config كخط أساسي للمنصة.
- راجع كل نص كُتب سابقًا بأي مرحلة منفّذة (Landing، Auth، أي صفحة) وتأكد أنه الآن يمر عبر نظام الترجمة ويظهر عربي RTL افتراضيًا.

---

## 2) معيار تصميم عالمي لصفحة Landing (Premium Standard)

الشكل الحالي (إن وُجد) يجب أن يُعاد بناؤه ليطابق جودة تصميم شركات SaaS العالمية الكبرى (Stripe, Linear, Vercel, Framer) — مو "قالب تعليمي" أو تصميم عام. تفاصيل ملزمة:

### Hero Section

- خلفية بـ Gradient/Mesh ناعم متحرك بهدوء جدًا (subtle animated gradient)، بدون إغراق العين.
- عنوان رئيسي كبير وقوي (Typography Scale واضح، Font weight عالٍ)، مع عنوان فرعي بسيط ومباشر.
- **معاينة حية مصغّرة لتقرير حقيقي** (Live report mockup) داخل الـ Hero نفسه — ليس بس نص وزر، إحساس فوري بالمنتج قبل ما يجرّب المستخدم.
- CTA بارز واحد رئيسي (حقل يوزر + زر تحليل)، بدون تشتيت بعدة أزرار متنافسة.

### التفاعل والحركة (Micro-interactions)

- Hover states ناعمة بـ transition واضح على كل عنصر تفاعلي (أزرار، بطاقات).
- Animate on scroll خفيف (fade/slide-in) للأقسام عند ظهورها بالشاشة — استخدم Framer Motion أو CSS transitions بسيطة، بدون مبالغة تبطئ الصفحة.
- عداد متحرك (Count-up animation) للأرقام المهمة (عدد التحليلات، عدد المستخدمين...) عند دخولها إطار الشاشة.

### قسم "كيف يعمل" (How it works)

- 3 خطوات بسيطة، كل خطوة بأيقونة/رسم توضيحي بسيط (SVG/lucide-react)، نص مختصر لكل خطوة.

### الإثبات الاجتماعي والثقة

- قسم شهادات/أرقام ثقة بتصميم بطاقات أنيقة (حتى لو المحتوى Placeholder مبدئيًا، البنية والتصميم يكونان جاهزين بمستوى احترافي).

### Footer

- منظم بأعمدة واضحة (روابط المنتج، الشركة، قانوني)، لا يكون سطر واحد مختصر.

### الجودة البصرية العامة

- مسافات بيضاء سخية (Generous whitespace) — لا ازدحام.
- Grid System منظم ومتّسق عبر كل الأقسام.
- دعم Dark mode (اختياري لكن مفضّل — أغلب هذه المواقع العالمية عندها Dark mode).
- الصور/الرسوم بـ Lazy loading، بدون Layout shift عند التحميل.
- استهداف نتائج Lighthouse عالية (Performance, Accessibility) — لا تضحّي بالأداء مقابل الحركة البصرية.

---

## معيار القبول لهذا الـ Addendum

1. فتح `/` من متصفح جديد (بدون أي إعداد لغة سابق) يعرض عربي RTL فورًا، بخط عربي واضح، بدون أي نص إنجليزي متبقٍ في المحتوى الأساسي.
2. مبدّل اللغة يعمل فعليًا وينقل لنسخة إنجليزية LTR كاملة دون كسر التخطيط.
3. صفحة Landing تعطي انطباعًا بصريًا فوريًا يوازي مستوى شركات SaaS عالمية معروفة — راجعها بعينك، مو بس وظيفيًا.
4. لا نص Hardcoded متبقٍ خارج ملفات الترجمة في أي صفحة تم بناؤها حتى الآن.

قدّم عند الانتهاء: وصف مختصر لما تغيّر، وتأكيد أن كل الصفحات المبنية سابقًا (Landing، Auth إن وُجدت) صارت تتبع هذا المعيار.
