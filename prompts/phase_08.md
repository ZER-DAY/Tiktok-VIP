# Phase 08 — Deployment على سيرفر Ubuntu

المرجع الملزم: `docs/18_DEPLOYMENT.md` (كامل)، `docs/17_SECURITY.md`.

## الهدف

نشر المشروع فعليًا على Staging ثم Production على سيرفر Ubuntu، مع CI/CD كامل ومراقبة أساسية، بحيث يكون المنتج قابلاً للوصول من مستخدمين حقيقيين بثقة.

## المهام

1. إعداد GitHub Actions Pipeline كما في `docs/18_DEPLOYMENT.md`: Install → Lint → Typecheck → Test → Build، على كل Pull Request.
2. Pipeline نشر تلقائي إلى Staging عند الدمج في `main`.
3. بوابة موافقة يدوية قبل النشر إلى Production.
4. تجهيز بيئة Production على السيرفر: PostgreSQL، Redis، Object storage متوافق مع S3، عملية Workers منفصلة عن Web process (عبر Docker Compose أو PM2/systemd).
5. `prisma migrate deploy` كخطوة إلزامية ضمن عملية النشر، لا تعديل يدوي لقاعدة بيانات الإنتاج تحت أي ظرف.
6. تفعيل كل متغيرات البيئة الفعلية (`docs/18_DEPLOYMENT.md`) بشكل آمن على السيرفر (ملف `.env` بصلاحيات محدودة أو Secrets manager، ليس ملفات نص عامة الوصول).
7. تفعيل مزود دفع فعلي (Stripe أو مكافئ) وربطه بجدول `Plan`/`Subscription` — كانت هذه الحقول Placeholder في `phase_05`، تُفعَّل بالكامل هنا.
8. `GET /api/health` مرتبط فعليًا بأداة مراقبة/السيرفر (Cron check أو أداة مراقبة خفيفة).
9. تنبيهات أساسية: فشل Jobs مرتفع، توقف DB، ارتفاع زمن استجابة.
10. نسخ احتياطي يومي تلقائي لقاعدة البيانات + **نسخ احتياطي دوري لمجلد المشروع كاملاً (بما فيه `docs/` و`prompts/`) خارج السيرفر** + توثيق خطوات الاستعادة (Restore) واختبارها فعليًا مرة واحدة على الأقل.
11. تفعيل HTTPS/HSTS (Let's Encrypt عبر Certbot أو مكافئ)، مراجعة نهائية لكل بند في `docs/17_SECURITY.md` قبل الإعلان عن الإطلاق العام.
12. نشر سياسة الخصوصية وشروط الاستخدام (`/privacy`, `/terms`) بمحتوى عربي فعلي يعكس طبيعة البيانات التقديرية وعدم الانتماء الرسمي لـ TikTok.

## معيار القبول (Phase Gate)

- نشر فعلي ناجح على Staging يعمل من طرف لطرف (تحليل حساب حقيقي، تسجيل مستخدم، تقديم طلب وكالة) بواجهة عربية RTL.
- Pipeline CI/CD يمنع فعليًا دمج كود يفشل أي اختبار أو Lint/Typecheck.
- استعادة نسخة احتياطية تجريبية ناجحة موثّقة (قاعدة البيانات + مجلد المشروع).
- كل بند في `docs/17_SECURITY.md` مُراجَع صراحة وليس مفترضًا.

قدّم عند الانتهاء: رابط/وصف بيئة Staging العاملة، ونتيجة اختبار الاستعادة الاحتياطية.
