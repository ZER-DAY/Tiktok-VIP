# UI-00 — تدقيق الواجهات

نفّذ تدقيقًا فقط، دون إعادة تصميم.

1. اقرأ master و`docs/21_ARABIC_UI_REDESIGN.md`.
2. شغّل المشروع وافحص كل route داخل `src/app/[locale]` بالعربية والإنجليزية.
3. أنشئ `docs/ui-audit.md` وفيه جدول: الصفحة، المشكلة، شدتها، RTL، mobile، accessibility، وحالات البيانات الناقصة.
4. ابحث عن النصوص الظاهرة hardcoded، ألوان/مسافات مكررة، مكونات متكررة، وملفات تتجاوز الحجم المعقول.
5. أنشئ `docs/ui-reference-log.md` بقالب فارغ وتعليمات التسجيل، ثم اختر مراجع المرحلة التالية فقط.
6. سجل baseline لنتائج typecheck/lint/test/build، ولا تصلح مشاكل خارج نطاق التدقيق.

معيار القبول: جرد كامل، قائمة أولويات P0/P1/P2، وخطة ملفات دقيقة لـ UI-01.
