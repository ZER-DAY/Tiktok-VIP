# UI-02 — التسويق والمصادقة

أعد تصميم Landing والمصادقة والصفحات القانونية باستخدام نظام UI-01.

المرجع البصري المباشر: `docs/ui-concepts/01-landing-ar-rtl.png`. أعد بناءه بمكونات حقيقية ولا تستخدم الصورة داخل الصفحة.

- راجع مراجع Hero وSaaS landing وauth، وسجل رابطين كحد أقصى لكل نمط.
- اجعل حقل تحليل TikTok هو الإجراء الأساسي الوحيد فوق الطيّة.
- Hero عربي قوي مع معاينة تقرير مفهومة، لا dashboard مصغر مزدحم.
- أعد ترتيب أقسام المزايا، كيف يعمل، الثقة، الأسعار، والوكالة كسرد مقنع وقصير.
- حسّن Navbar وFooter ومبدّل اللغة والموبايل.
- وحّد Login/Register/Forgot password مع validation وloading/error وpassword visibility وautofill صحيح.
- لا تخترع أرقام عملاء أو شهادات حقيقية؛ أي محتوى عرض يجب أن يكون عامًا وغير مضلل.
- حافظ على endpoints والتدفقات الحالية.

افحص `/`, `/en`, login, register, forgot-password, privacy, terms على المقاسات الثلاثة، ثم نفّذ بوابة الجودة.
