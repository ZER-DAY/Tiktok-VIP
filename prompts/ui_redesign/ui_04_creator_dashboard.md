# UI-04 — لوحة المبدع

أعد تصميم Dashboard وAccounts وAccount details وCompare وSettings.

المرجع البصري المباشر: `docs/ui-concepts/03-creator-dashboard-ar-rtl.png`. اتبع تسلسل: ماذا تغيّر، لماذا، وما الإجراء التالي.

- استخدم AppShell المشترك ولا تنشئ تنقلًا موازيًا.
- رتّب الصفحة حسب قرارات المستخدم: ماذا حدث؟ لماذا؟ ماذا أفعل الآن؟
- اجعل الرسوم والجداول RTL سليمة مع tooltips وألوان وتباين مفهوم.
- على الموبايل حوّل الجداول غير المناسبة إلى cards أو عرض تفصيلي، دون تمرير أفقي عشوائي.
- أضف empty states تقود للتحليل الأول، وحالات loading/error حقيقية.
- المقارنة يجب أن توضح الفروق لا أن تعرض أرقامًا متجاورة فقط.
- الإعدادات الحساسة، خصوصًا الحذف، تحتاج تأكيدًا واضحًا وغير مضلل.

تحقق من الصلاحيات وعدم تسريب تقارير مستخدم آخر، ثم نفّذ بوابة الجودة.
