# UI-05 — CRM الوكالة

أعد تصميم قائمة المتقدمين وصفحة المتقدم وتدفق العمل.

المرجع البصري المباشر: `docs/ui-concepts/04-agency-admin-ar-rtl.png`، خصوصًا كثافة الجدول والـ detail drawer ومعالجة الخصوصية.

- قائمة قابلة للبحث والفلترة مع filters واضحة وقابلة للمسح وحالة لا نتائج.
- اجعل status workflow ظاهرًا ومفهومًا، مع تأكيد التغييرات المهمة وتغذية راجعة بعد الحفظ.
- نظم ملف المتقدم إلى: هوية واتصال، ملخص حساب TikTok، تقرير التأهيل، الملاحظات، المسؤول، وسجل الحالة.
- أخفِ البيانات الشخصية عن أي role غير مخول، ولا تعرضها في logs أو رسائل خطأ.
- الملاحظات تبيّن الكاتب والوقت، وتمنع الإرسال المكرر أثناء loading.
- صمم الهاتف للاستخدام الفعلي من موظف التوظيف.

اختبر roles المسموحة والمرفوضة، ar/en، حالات البيانات الأربع، ثم بوابة الجودة.
