# UI-06 — الإدارة وضمان الجودة النهائي

أعد تصميم Stats وUsers وPlans وSettings وAudit logs، ثم نفّذ تدقيق المنتج كاملًا.

المرجع البصري المباشر: القسم السفلي والإجراءات الإدارية في `docs/ui-concepts/04-agency-admin-ar-rtl.png`.

- وحّد cards والجداول والفلاتر والنماذج مع بقية النظام.
- أبرز الإجراءات الحساسة وافصلها عن الإجراءات اليومية، مع confirmation ورسائل نجاح/فشل.
- سجل التدقيق يجب أن يكون سهل البحث والقراءة دون كشف أسرار.
- لا تغيّر صلاحيات RBAC أو العقود الخلفية أثناء التحسين البصري.
- راجع كل routes في ar/en عند 360/768/1440، keyboard-only، reduced motion، contrast، overflow، loading/empty/error.
- راجع `docs/ui-audit.md` وأغلق البنود أو دوّن سببًا حقيقيًا لكل بند متبقٍ.
- شغّل typecheck وlint وtest وbuild، واختبر `/api/health` والمسارات الحرجة يدويًا.

التسليم النهائي: تقرير قبل/بعد، قائمة الصفحات المنجزة، نتائج الجودة، وأي مخاطر إطلاق متبقية.
